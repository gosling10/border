Различные свойства и виды Border

1. Сплошная классика
Solid
border: 4px solid #f43f5e;
2. Разные стили сторон
Mixed
border-top: 4px dashed;
border-left: 4px dotted;
3. Двойная рамка (Double)
Double
border: 6px double #a855f7;
4. Сложная геометрия углов
Кучка
border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%;
5. Псевдо-3D объем
3D Иллюзия
/* Разный цвет сторон */
border-top: 8px solid #64748b;
border-bottom: 8px solid #1e293b;
6. Градиентная граница
Gradient
border: 5px solid;
border-image: linear-gradient(...) 1;
7. Интерактивная рамка
Наведи меня
border-color: #f59e0b;
box-shadow: 0 0 15px...
transition: all 0.3s;
8. Двойной контур (Outline)
Offset
border: 2px solid;
outline: 2px dashed;
outline-offset: 4px;
9. Фигуры из border (Треугольник)
width: 0; height: 0;
